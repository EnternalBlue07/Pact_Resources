# PACT: Technology & AI Disclosure Statement

> [!NOTE]
> **TRANSPARENCY & ATTRIBUTION DISCLOSURE**  
> In compliance with CodeHack India regulations regarding open disclosure of tools, libraries, third-party assets, and AI assistants, this document provides a comprehensive accounting of all technologies employed in the PACT project.

## 1. Development Window Attestation

- **Pre-Hackathon Preparation**: Repository initialization, Markdown specification documents, test plans, issue templates, and architecture designs were structured during initial project setup.
- **Official Build Window**: All functional frontend components, backend endpoints, database models, business logic algorithms, and automated test implementations will be authored strictly during the official 48-hour hackathon window.
- **Pre-Existing Functional Code**: **None.** No application code, pre-built components, or pre-configured databases exist prior to the official start.

## 3. Frameworks & Open-Source Libraries

### Frontend Libraries (Planned)
- **React 18 / 19**: Frontend UI component library (MIT License).
- **Vite**: Next-generation frontend build tooling and local dev server (MIT License).
- **TypeScript**: Static typing and interface contracts (Apache 2.0 License).
- **Tailwind CSS**: Utility-first CSS styling framework (MIT License).
- **Lucide React**: Clean, accessible open-source iconography (ISC License).

### Backend Libraries (Planned)
- **Python 3.11+**: Core backend runtime (PSF License).
- **FastAPI**: Modern, asynchronous web framework for building APIs (MIT License).
- **Uvicorn**: High-performance ASGI web server (BSD-3-Clause License).
- **Pydantic V2**: Data parsing, serialization, and schema validation (MIT License).
- **SQLAlchemy 2.0**: Relational SQL toolkit and Object-Relational Mapper (MIT License).
- **Python-JOSE / PyJWT**: JSON Web Token encoding, decoding, and signature verification (MIT License).
- **Passlib / Bcrypt**: Password hashing and verification algorithms (BSD License).

### Testing & Quality Tooling (Planned)
- **Pytest & Pytest-Asyncio**: Python unit and asynchronous API testing framework (MIT License).
- **HTTPX**: Asynchronous HTTP client for API integration tests (BSD-3-Clause License).
- **Ruff**: Fast Python linter and code formatter (MIT License).
